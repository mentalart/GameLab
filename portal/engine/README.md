# Движок игр курса: three.js + оболочка «Лаб3D 1.0»

Игра-донор учителя — один объект `GAME` на обычном three.js. Оболочка `lab-three.js` — не движок, а служебный слой, одинаковый для всех игр: жизненный цикл партии и экраны, ввод (клавиатура, два геймпада, тач), «Ручки геймдизайнера» с пресетами, камера, свет, тени, свечение, сочность, звук, случайность по зерну, телеметрия, рекорды, призрак соперника, бот-плейтестер и связь с порталом. Стандарты курса оболочка выполняет сама, игра пишет только механику и мир.

Babylon.js в курсе не используется (решение автора 18.10.2026): доноры уроков 1–8 переписаны на three.js, старая оболочка Babylon удалена 19.10.2026. Игры учеников из chat.qwen.ai — страницы HTML с мостом `portal.js`, оболочку они не используют.

| Файл | Что это |
| --- | --- |
| `game.html` | Страница игры: холст, HUD, экраны старта, паузы и конца, панель ручек. Код игры — `?game=путь.js` или вместо `<!--GAME-->` |
| `lab-three.js` | Оболочка «Лаб3D» 1.0 (модуль ES): API `lab`, протокол портала, бот-плейтестер |
| `vendor/three/` | three.js 0.170.0 (`three.module.min.js`) и нужные дополнения в `addons/`. Обновляет только `bash portal/tools/vendor-three.sh [версия]` — tarball из registry.npmjs.org (CDN из среды Claude закрыт) |
| `portal.js` | Мост для игр-страниц из chat.qwen.ai: ручки, конец партии, рекорды, счётчики, телеметрия партии, записи программиста, ошибки (см. ниже) |

## Мост `portal.js` для игр-страниц из чата

Портал вставляет мост первым в `<head>` каждой игры-страницы. Игра вызывает:

| Вызов | Что делает |
| --- | --- |
| `const cfg = portal.knobs({ speed: { value, min, max, step, label } }, { 'Новичок': {...} })` | Ручки геймдизайнера и пресеты; панель — Tab или Select геймпада, пока она открыта, `portal.paused` |
| `portal.over(очки)`, `portal.again()` | Конец партии (рекорды, плейтест, телеметрия) и новая партия |
| `portal.score(очки)` | Текущий счёт: из него кривая партии по секундам в разборе прототипа |
| `portal.hurt()` | Герою нанесён урон |
| `portal.count('_secret')` | Сработала спрятанная механика: счётчик и секунда партии для полоски спрятанной механики (имена с `_` — скрытые счётчики) |
| `portal.notes(['...'])` | Что программист решил сам, чего не было в замысле. Портал читает записи из кода для «Найди, где ИИ своевольничал» |
| `portal.onRecord = (рекорд, мой) => {}` | Рекорд класса |
| `portal.input` | `'pad'` или `'keys'`: чем игрок управляет сейчас. Подписи кнопок игра пишет парой `<span class="keys-only">Пробел</span><span class="pad-only">A</span>`, мост показывает нужную: подключён геймпад или нажата его кнопка — `pad-only`, нажата клавиша — `keys-only` |

Страховка конца партии: если после `portal.over()` нажали Start на геймпаде, а игра сама не начала партию (`portal.again()`), мост нажимает за неё Enter, потом R.

Остальную телеметрию мост считает сам и отдаёт с `over` в тех же полях, что оболочка: `time` (партия без пауз), `presses` и `hold` (клавиатура: стрелки, WASD, пробел, Shift; геймпад: крестовина, стик, A, B), `hurts`, `custom`, `marks`, `line` (счёт по секундам). Ошибки со строкой мост сообщает порталу, и портал выдаёт сообщение для того же чата.

## Запуск и проверка

```bash
node portal/tools/serve.js     # http://localhost:8080/engine/game.html?game=../games/zvezdopad.js
```

Ссылка у всех игр одна: `/engine/game.html?game=../games/имя.js`. `&seed=12345` фиксирует случайность: тот же мир для друга.

```bash
node portal/tools/check-game.js                    # все игры из portal/games/
node portal/tools/check-game.js games/игра.js      # одна игра
node portal/tools/check-game.js --self             # плюс проверка оболочки: ошибка со строкой из кода игры
node portal/tools/playtest.js games/игра.js        # бот-плейтестер: три стратегии, выводы на русском
```

Проверка запускает игру в Chromium без окна (Playwright) и проверяет: загрузку без ошибок, непустую картинку, старт пробелом и геймпадом, что стартовое нажатие не засчитывается, стик, клавиатуру и короткие нажатия, 6 секунд случайной игры и каждый пресет, панель ручек и «Как задумано», перезапуск R быстрее секунды, экран конца партии, бюджет — не больше 250 вызовов отрисовки за кадр (тени, сцена и свечение вместе). Снимки и `report.json` — в `portal/.check/` (не в git).

## Контракт объекта GAME

```js
const GAME = {
  engine: 'three',                         // отметка движка: все игры-объекты курса — на three.js
  title: 'Звездопад над Фиштом',           // обязательно
  subtitle: 'Одна фраза: цель игры',
  donor: 'граза из bullet hell',           // «по мотивам механики …» на стартовом экране
  players: 1,                              // 1 или 2
  duo: 'vs',                               // необязательно: при ручке vs ≥ 1 игра на одного становится игрой на двоих
  controls: [{ input: 'move4', text: 'бежать' }, { input: 'a', text: 'рывок' }],
  camera: { type: 'iso', tilt: 0.85 },     // или 'iso', 'top', 'diorama', 'side', 'behind', 'free'
  field: { w: 24, h: 18 },                 // игровое поле в метрах: камера сама держит его целиком в кадре
  sky: ['#141a3f', '#d9776b'],             // верх неба и горизонт (или один цвет), fog — плотность тумана цвета горизонта
  fog: 0.012, accent: '#ffd76a',
  decisions: ['Чувство: …', 'Честность: …', 'Выбор: …'],
  notes: ['Что программист решил сам'],
  config: { speed: { value: 8, min: 2, max: 20, step: 0.5, label: 'Скорость', hint: 'подсказка', restart: false } },
  presets: { 'Новичок': { speed: 5 }, 'Без спрятанной механики': { secret: 0 } },
  start(lab, scene) { /* построить мир новой партии */ },
  update(lab, dt) { /* один кадр игры */ },
  overNote(lab) { return ['Точность: 48%']; },
};
```

| Поле | Обязательно | Что делает |
| --- | --- | --- |
| `engine` | нет | `'three'` — отметка движка, у всех доноров есть |
| `title` | да | Название на стартовом экране и ключ рекорда (если нет `id`) |
| `start(lab, scene)` | да | Строит мир новой партии на новой чистой сцене (`THREE.Scene`). Вызывается при каждом старте и перезапуске. Состояние партии — в `lab.state` |
| `update(lab, dt)` | да | Один кадр игры. `dt` — секунды, не больше 0,05 (с замедлением `lab.slowmo` — меньше). Не вызывается в меню, на паузе, в стоп-кадре и после конца партии |
| `controls` | да | `{ input, text }`, `input`: `move` (← →), `move4` (← → ↑ ↓), `a`, `b`. По ним подписи на экранах и кнопки тача |
| `config` | да | Ручки: `value, min, max, step, label`, по желанию `hint`, `restart: true` (перестроить партию), `names` (подписи значений). Значения — `lab.cfg.имя`. Ручка `lives` задаёт стартовые жизни |
| `presets` | да | Наборы значений ручек. «Как задумано» оболочка добавляет сама, «Новичок» обязателен. Пресет может менять и переключатели сочности `j_…` |
| `decisions` | да | Три решения: чувство, честность, выбор. Видны на стартовом экране |
| `camera` | нет | Вид камеры, см. «Камера» |
| `field` | нет | `{ w, h }` в метрах, центр в начале координат. По нему камера держит поле в кадре, а тень солнца — нужного размера |
| `players`, `duo` | нет | Вдвоём: игроки делят клавиатуру (WASD + F/G и стрелки + K/L) или берут по геймпаду. `duo` — имя ручки: пока она ≥ 1, игра на одного работает как игра на двоих, `lab.players` в `start` уже 2. Ручку ставят с `restart: true` и пресетом «Вдвоём» |
| `pace` | нет | `'turns'` — пошаговая игра: бот не считает ошибкой ожидание хода |
| `sky`, `fog`, `accent` | нет | Небо (цвет или `[верх, горизонт]`), туман цвета горизонта, цвет всплывающих очков |
| `shadowSize` | нет | Полуширина области теней в метрах (по умолчанию из `field`) |
| `donor`, `subtitle`, `id`, `lives`, `notes` | нет | Подпись донора, подзаголовок, ключ рекорда, жизни без ручки `lives`, решения программиста |
| `overNote(lab)` | нет | Строка или массив строк для экрана конца партии |

Код игры — классический скрипт: `const GAME = {...}` на верхнем уровне, методы вызываются как `GAME.start(...)`, поэтому `this` — сам GAME, и помощники кладут в него же (`this.buildWave(lab)`). Глобальный `THREE` (он же `lab.THREE`) готов внутри `start` и `update`; **на верхнем уровне файла THREE не трогать** — оболочка (модуль) загружается позже кода, вставленного в страницу. Физики в оболочке нет: движение и столкновения игра считает сама (донорам уроков 1–8 физика не нужна).

## Система координат

Обычная для three.js — правая:

- Ось Y — вверх, земля — плоскость XZ на высоте 0. Метр: человек ≈ 1,8, дом ≈ 3.
- Виды `top`, `iso`, `diorama` смотрят со стороны +Z (от игрока) в сторону −Z. **+X — вправо по экрану, −Z — «вверх по экрану», вдаль.** Поле `field` лежит в центре: X от −w/2 до w/2, Z от −h/2 до h/2.
- `lab.p1.y` положительный, когда игрок жмёт вверх, поэтому в видах сверху `z -= p1.y * скорость * dt`. Направление стика на земле: `[p.x, -p.y]`.
- Вид `side` смотрит вдоль −Z на плоскость XY: X — вправо, Y — вверх, поле от Y = 0 до Y = h. Глубина Z — для фона (дальше — меньше Z).
- «Вперёд» у героя — его локальная +Z: `rotation.y = Math.atan2(vx, vz)` поворачивает его по скорости. Вид `behind` встаёт за спиной по `rotation.y`.

## Камера

`camera` в GAME или `lab.setCamera(вид, опции)` в `start`:

| Вид | Что это |
| --- | --- |
| `iso` (по умолчанию) | Наклон 0,88 рад от вертикали |
| `top` | Почти сверху (0,18) |
| `diorama` | Наклон 0,95 и поворот на 45° |
| `side` | Сбоку, плоскость XY |
| `behind` | За героем: `lab.follow(герой, { distance: 9, height: 4, lag: 0.15, look: 1 })` |
| `free` | Оболочка камеру не двигает, `lab.camera` (PerspectiveCamera) ставит игра |

Опции: `tilt` (наклон от вертикали, рад; `beta` — то же), `turn` (поворот вокруг Y, 0 — со стороны +Z), `target: [x, y, z]`, `distance` (иначе оболочка подбирает расстояние так, чтобы **все четыре угла поля** были в кадре при любом размере окна), `fov` (рад, по умолчанию 0,8). Штатив — `lab.view`: `{ kind, tilt, turn, distance, target }`, его можно менять каждый кадр (наезд камеры, разворот). `lab.follow(меш)` в видах сверху плавно ведёт цель камеры за героем. Тряска `lab.shake` добавляется к любой камере, включая `free`, и не сбивает её. Солнце ходит за целью камеры: тени есть там, где идёт игра.

## Объект lab

| Группа | Что есть |
| --- | --- |
| three.js | `lab.THREE`, `lab.renderer`, `lab.scene`, `lab.camera`, `lab.view`, `lab.light.hemi`, `lab.light.sun`, `lab.shadows` (включены ли тени), `lab.addons` — `BufferGeometryUtils`, `SkeletonUtils`, `RoundedBoxGeometry`, `GLTFLoader`, `SimplexNoise` |
| Партия | `lab.t`, `lab.dt`, `lab.state` (обнуляется при перезапуске), `lab.cfg`, `lab.seed`, `lab.round`, `lab.playing`, `lab.players`, `lab.data` (данные портала, например мелодия урока 7 `lab.data.melody`; пришли — партия в меню перестраивается) |
| Ввод | `lab.p1`, `lab.p2`: зажатые `left right up down a b`; `pressed.a` — нажата в этом кадре; `released.a` — отпущена; `x`, `y` — оси от −1 до 1. В играх с `move` стрелка вверх — тоже A. Нажатие, которым запущена партия, не засчитывается; короткое нажатие между кадрами не теряется |
| Очки и жизни | `lab.score`, `lab.lives`, `lab.best`, `lab.addScore(n, где, цвет)`, `lab.hurt(где, текстПроигрыша)` → `true`, если удар прошёл (неуязвимость 1,2 с, тряска, вспышка, волна, звук, вибрация, при 0 жизней — конец), `lab.invuln`, `lab.blink()` → мигать ли героем, `lab.gameOver(текст)`, `lab.win(текст)` |
| Сочность | `lab.shake(0..1)`, `lab.flash(цвет, 0..1)`, `lab.hitstop(сек)`, `lab.burst(где, { count, color или colors, speed, size, life, gravity, up, dir })` — искры (ярче белого, дают ореол; `dir` — летят сквозь врага по удару), `lab.ring(где, { color, radius, life, from })` — ударная волна по земле, `lab.trail(объект, { color, width, length, glow })` → `{ clear(), dispose() }` — светящийся след за летящим объектом (огненный хвост снаряда, рывок), `lab.popup(где, текст, цвет, размер)` — выпрыгивающая надпись, `lab.pulse(объект, k, сек)` — сжатие и растяжение, `lab.whiten(объект, сек, цвет)` — вспышка попадания (не для копий InstancedMesh), `lab.warn(где, радиус, сек, цвет)` → `{ left, dispose() }` — круг-предупреждение, мигает чаще перед ударом, `lab.vibrate(мс, сила)`, `lab.slowmo(сек, 0.3)`, `lab.pitch(n)` — множитель частоты n-го удара подряд, `lab.juicy('squash')` — включён ли переключатель |
| Плавность | `lab.tween(сек, (k, сырое) => {...}, 'outBack')` → `{ cancel() }` — функция получает k от 0 до 1 по кривой; `lab.ease` — `linear, inQuad, outQuad, inOutQuad, inCubic, outCubic, inOutCubic, outBack, outElastic, outBounce`; `lab.after(сек, fn)` — таймер игрового времени; `lab.damp(a, b, скорость, dt)` — плавное приближение, не зависит от частоты кадров. Твины и таймеры стоят на паузе и в стоп-кадре и сбрасываются при перезапуске |
| Звук | `lab.sfx.jump/shoot/coin/hit/explode/power/beep/warn/whoosh/win/lose()`, `lab.tone(частота, сек, 'square'/'sine'/'triangle'/'sawtooth', громкость, скольжениеДо, задержка)`, `lab.noise(сек, громкость, частотаФильтра, задержка)`. Без файлов, через компрессор: много звуков разом не хрипят |
| Случайность | Только через зерно: `lab.rand(a, b)`, `lab.randInt(a, b)`, `lab.pick(массив)`, `lab.chance(p)`. `Math.random` в игре не используется — иначе `?seed=` не повторит мир |
| Математика | `lab.clamp`, `lab.lerp`, `lab.v3(x, y, z)` (Vector3), `lab.dist(a, b)`, `lab.flat(a, b)` (по земле), `lab.near(a, b, r)`, `lab.toScreen(где)` → `{ x, y, visible }`. «Где» — объект сцены (берётся мировая позиция), Vector3, `{x, y, z}` или `[x, y, z]` |
| Мир | см. ниже |
| Интерфейс | `lab.hud('ключ', 'текст')` (`null` убирает), `lab.count('имя', n)` — счётчик телеметрии (имя с `_` — скрытый: уходит порталу, на экран не попадает; так считается спрятанная механика `_secret`, её секунды копятся в `marks`), `lab.stat('имя', значение)` |

### Мир: лоуполи-детали

| Вызов | Что делает |
| --- | --- |
| `lab.mat(цвет, { glow, alpha, unlit, shiny, smooth, metal, rough, add, side: 'double' })` | Материал из кэша партии. По умолчанию `MeshStandardMaterial` с плоскими гранями (лоуполи). `glow: 0..2` — светится и даёт ореол свечения (ручка «Свечение» и переключатель `j_glow` действуют сразу); `unlit` — без света; `alpha` — прозрачность; `add` — сложение цвета (огонь, лучи); `smooth` — гладкие грани |
| `lab.box(w, h, d, цвет, о)`, `lab.ball(r, цвет, о)`, `lab.cyl(rВерх, rНиз, h, цвет, о)`, `lab.cone(r, h, цвет, о)`, `lab.group(о)`, `lab.mesh(геометрия, цвет или материал, о)` | Готовый меш в сцене. `о`: `at: [x, y, z]`, `rot` (число — вокруг Y, или `[x, y, z]`), `scale` (число или `[x, y, z]`), `parent` (группа; `null` — не добавлять), `shadow: false`, `sides` (граней у цилиндра и конуса), `detail` (0–2 у шара), `round` (скругление коробки), плюс опции материала |
| `lab.ground({ w, h, color, y, bumps, flat })` | Земля. `bumps` — лоуполи-холмы к краям, в середине (доля `flat`) ровно |
| `lab.instances(геометрия, цвет или материал, n, о)` + `lab.place(копии, i, где, { rot, scale, color })` | Повторяющиеся предметы одной пачкой: 120 деревьев — 1 вызов отрисовки. Неразмещённые копии не видны |
| `lab.merge([меши или группы], родитель)` | Слить неподвижные меши в один на материал (горы, забор, дом из коробок) |
| `lab.add(объект, родитель)` | Добавить свой объект three.js |
| `lab.shadow(объект)`, `lab.noShadow(объект)` | Каждый новый меш сам отбрасывает и принимает тень; `noShadow` — не отбрасывать (вспышки, следы, круги) |
| `lab.hero(объект)` | Главный герой: по нему бот-плейтестер проверяет, что герой в кадре (`lab.follow` задаёт его тоже) |
| `lab.follow(объект, опции)`, `lab.setCamera(вид, опции)` | Камера, см. выше |

Бюджет: до 250 вызовов отрисовки за кадр (каждый меш — вызов в сцене и ещё один в тени). Повторяющееся — `lab.instances`, неподвижное — `lab.merge`. У образца «Звездопад» 25 мешей и около 60 вызовов при 120 деревьях и 70 камнях.

## Графика оболочки

- Нейтральная тонировка (`NeutralToneMapping`), цвета в sRGB, свет неба (`HemisphereLight` в цвет неба) и солнце с мягкими тенями (`PCFSoftShadowMap`), небо-градиент и туман цвета горизонта.
- Свечение — постобработка `UnrealBloomPass`: светится только то, что ярче белого (`glow`, искры, волны, следы, вспышки попадания).
- Ручка «Качество графики»: «быстро» — без теней и свечения, мелкое разрешение; «обычно» — тени 1024, свечение, сглаживание MSAA ×2; «красиво» — тени 2048, MSAA ×4, отражения окружения (`RoomEnvironment`) на гладком.
- Своё разрешение: если кадр дольше 34 мс, оболочка уменьшает разрешение холста (до половины), когда снова быстро — возвращает. Игра и ручки этого не замечают.
- Автопроверки ставят `window.LAB_LOWRES`: половина разрешения, а меню, пауза и экран конца партии рисуются 5 раз в секунду — без видеокарты стоящие игры иначе съедают процессор соседних окон.

## Что делает оболочка (в игре этого не пишут)

- Экран старта с названием, донором, кнопками (клавиатура или геймпад — по последнему устройству) и тремя решениями. Пауза (P, Esc, Start, уход со вкладки). Экран конца партии: очки, время, личный рекорд, рекорд класса, заметки `overNote`, телеметрия, зерно. На геймпаде экран конца партии закрывает только Start, на клавиатуре и таче он не закрывается первые 0,8 с.
- Перезапуск: R, пробел или A после конца партии; партия строится заново на чистой сцене (старая освобождается целиком).
- Панель «Ручки геймдизайнера» (Tab или Select): ручки игры, пресеты, «Как задумано», ручки оболочки (тряска, сочность частиц, свечение, качество), «Сочность: 12 переключателей», «Скопировать настройки».
- 12 переключателей сочности урока 6 (`j_hitstop`, `j_shake`, `j_squash`, `j_burst`, `j_flash`, `j_whiten`, `j_popup`, `j_sound`, `j_pitch`, `j_vibrate`, `j_glow`, `j_slowmo`): каждый выключает свой эффект оболочки в любой игре (`j_burst` — искры и волны, `j_squash` — ещё и подскок счёта), механика остаётся той же. Портал выключает все 12 в слепой пробе «сухая или сочная».
- Звук M. Ошибка в коде игры останавливает игру и показывает сообщение со строкой **из кода игры** (кадры three.js и оболочки пропускаются); портал получает её для починки. Ошибка на верхнем уровне файла игры тоже ловится.

## Связь с порталом

Игра работает в `iframe` (sandbox без `allow-same-origin`, поэтому статике `/engine/` и `/games/` нужен CORS — он есть в `server.js`).

| Направление | Сообщения |
| --- | --- |
| Игра → портал (`source: 'lab-game'`) | `ready` (`shell`, `engine: 'three'`, версия, описание игры `meta`), `start`, `again`, `over` (очки, рекорд, зерно, телеметрия `tele`, изменённые ручки `cfg`), `cfg`, `error` (фаза, текст, строка), `poster` (кадр для аркады), `playtest`, `playtestStep`, `showStep`, `showDone` |
| Портал → игра (`target: 'lab-game'`) | `records`, `seed`, `data` (`lab.data`, раньше `setCfg`), `setCfg` (копии А и Б, эксперимент с ручкой), `pause`, `poster`, `playtest`, `challengeOn`, `ghost` (`{ nick, score, line }` — призрак соперника под счётом), `reveal` (`{ title }` — лупа спрятанной механики), `botShow` (бот играет на проекторе) |

Телеметрия `tele`: `time`, `presses`, `hold`, `hurts`, `custom` (счётчики `lab.count`), `stats`, `marks` (секунды скрытых счётчиков), `line` (счёт на каждой секунде, до 600).

Для автопроверки и отладки — `window.__lab`: `ready`, `engine`, `state`, `paused`, `errored`, `lab`, `scene`, `tele`, `session`, `cfg`, `DEFAULTS`, `confirm()`, `restart()`, `end()`, `togglePanel()`, `playtest(опции)`, `botShow(опции)`, `setLupa(название)`, `lupa` (`{ title, n, on }`), `frames(n)` → Promise после n кадров, `info()` → `{ engine, version, draws, meshes, fps }`, `pixels()` → `{ colors, lit }`.

**Лупа спрятанной механики.** После «Найди спрятанную механику» портал шлёт `{ type: 'reveal', title }`. Оболочка показывает значок «🔍 Спрятанная механика: …» и зажигает его со счётом «× N» на каждом `lab.count('_secret')`; первое срабатывание — с тихим звуком. Мост HTML-игр (`portal.js`) делает то же на `portal.count('_secret')`. В ускоренных партиях бота лупа молчит.

## Бот-плейтестер

`window.__lab.playtest({ seconds: 90, seed: 12345, strategies: ['idle', 'mash', 'random'] })` — бот играет партию каждой стратегией в одном мире в ускоренном времени (шаг 1/30 с, без звука, рекорда и сообщений порталу): `idle` — ничего не жмёт, `mash` — мнёт A, `random` — бегает куда попало и жмёт A и B. Отчёт `{ results, findings }`: время, очки, урон и когда он был, процент времени героя за кадром, самая долгая пауза без очков, счётчики. Выводы на русском: игра упала, герой уходит за кадр, бездействие не наказано или очки идут без игры, доминирующая стратегия «мять A», слишком сложно для новичка, первый урон раньше 6-й секунды, пустое время, нет угрозы. Портал запускает его сообщением `playtest`, из консоли — `node portal/tools/playtest.js games/игра.js`.

В каждом результате есть `secretAt` — секунды срабатываний `_secret`. С `compare: { knob: 'secret' }` бот играет ещё одну партию новичком с этой ручкой в 0 и тем же зерном — она приходит в `report.off` (`playtestStep` с `off: true`). Сервер сравнивает копии: спрятанная механика слабая, если первое срабатывание позже 15-й секунды, реже 4 раз в минуту или копии почти не различаются.

**Показ бота в настоящем времени** (проектор «Спрятанная механика рядом»): `{ type: 'botShow', options: { seconds: 60, seed, strategy: 'random', mute } }`. Бот играет партию в темпе настоящего времени тем же шагом 1/30 с и тем же зерном, поэтому две копии с одним зерном расходятся только из-за ручек. По ходу — `{ type: 'showStep', t, seconds }`, в конце — `{ type: 'showDone', result: { seconds, score, hurts, over, secret } }`, потом игра возвращается в меню.

## Образец

`portal/games/zvezdopad.js` — «Звездопад над Фиштом», образец на новой оболочке (не донор урока). Ёжик собирает звёзды на плато Лаго-Наки, метеориты бьют в светящиеся круги. На нём видно:

- мир из лоуполи-деталей: холмы `ground({ bumps })`, горы через `lab.merge`, 120 пихт и 70 камней границы через `lab.instances`, луна со свечением, звёзды неба `THREE.Points`;
- герой из групп и деталей, бег с разгоном (`lab.damp`), рывок со следом (`lab.trail`) и неуязвимостью «сквозь метеорит»;
- честность: круг-предупреждение (`lab.warn`) и метеорит с огненным хвостом летит ровно в круг; камни показывают границу поля;
- сочность: серия звенит выше (`lab.pitch`), искры, волны, всплывающие очки, тряска по расстоянию, пятно от удара;
- спрятанная механика донора отдельной ручкой и пресетом «Без спрятанной механики»: граз — метеорит, упавший впритык, удваивает серию (`lab.count('_secret')`, `lab.slowmo`);
- 30 ручек вместе с оболочкой, пресеты «Новичок», «Без спрятанной механики», «Метеоритный дождь».
