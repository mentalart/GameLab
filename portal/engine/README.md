# Движок игр курса: Babylon.js + оболочка «Лаб3D»

Каждая игра курса — один объект `GAME` на обычном Babylon.js. Его пишет Qwen по замыслу ученика (системный промпт — `portal/ai/game-prompt.md`). Оболочка `lab.js` — не движок, а служебный слой, одинаковый для всех игр: жизненный цикл партии и экраны, ввод (клавиатура, два геймпада, тач), «Ручки геймдизайнера» с пресетами, камеры, свет и тени, сочность, звук, случайность по зерну, телеметрия, рекорды и связь с порталом. Благодаря ей стандарты курса выполняются в каждой игре сами, а Qwen пишет только механику и мир.

| Файл | Что это |
| --- | --- |
| `game.html` | Страница игры: холст, HUD, экраны старта, паузы и конца, панель ручек. Портал вставляет код игры вместо `<!--GAME-->` |
| `lab.js` | Оболочка «Лаб3D», версия 0.2 (0.2 — игра на двоих по ручке `duo`) |
| `vendor/` | Babylon.js 9.31.0, загрузчики моделей, физика Havok 1.3.14. Обновляется только workflow «Babylon.js в vendor» (`.github/workflows/vendor-babylon.yml`) |
| `vendor/babylon/babylon.d.ts` | Типы Babylon этой версии. По ним сверяется шпаргалка для Qwen |

## Запуск

```bash
node portal/tools/serve.js            # http://localhost:8080/ — откроется «НЛО в станице»
```

Любая игра: `http://localhost:8080/engine/game.html?game=../games/имя.js`. Параметр `&seed=12345` фиксирует случайность: тот же мир для друга. Нужен Node.js 18+, зависимостей нет. Открывать игры нужно через сервер: с `file://` физика Havok (WebAssembly) не загрузится.

Автопроверка в браузере без окна:

```bash
node portal/tools/check-game.js                         # все игры из portal/games/
node portal/tools/check-game.js games/моя-игра.js       # одна игра
node portal/tools/check-game.js --self                  # плюс проверка оболочки: физика и ловля ошибок
```

Проверка запускает игру в Chromium через Playwright. Она проверяет загрузку без ошибок и непустую картинку. Проверяет старт пробелом и геймпадом и то, что стартовое нажатие не засчитывается. Проверяет, что стик, клавиатура и короткие нажатия доходят до игры. Дальше — 6 секунд случайной игры и каждый пресет, панель ручек, «Как задумано», перезапуск R быстрее секунды, экран конца партии. Ещё она проверяет бюджет: не больше 250 вызовов отрисовки. Снимки экрана и `report.json` ложатся в `portal/.check/`, в репозиторий не попадают. Для проверки нужен Playwright: `npm i -g playwright && npx playwright install chromium`.

## Контракт объекта GAME

```js
const GAME = {
  title: 'НЛО в станице',                  // обязательно
  subtitle: 'Одна фраза: цель игры',
  donor: 'Space Invaders',                 // «по мотивам механики …» на стартовом экране
  players: 1,                              // 1 или 2 (на одной клавиатуре или двух геймпадах)
  duo: 'vs',                               // необязательно: при ручке vs ≥ 1 игра на одного становится игрой на двоих
  controls: [{ input: 'move', text: 'катить пушку' }, { input: 'a', text: 'выстрел' }],
  camera: 'iso',                           // или { type: 'iso', beta: 1.1, target: [0, 0, -4] }
  field: { w: 28, h: 30 },                 // игровое поле в метрах, по нему камера подбирает расстояние
  sky: '#162038', fog: 0.008, accent: '#ffe08a',
  physics: false, gravity: 9.81,           // physics: true включает Havok
  decisions: ['Чувство: …', 'Честность: …', 'Выбор: …'],
  notes: ['Что программист решил сам'],    // для плейтеста «где ИИ своевольничал», оболочка не показывает
  config: { speed: { value: 8, min: 2, max: 20, step: 0.5, label: 'Скорость', hint: 'подсказка', restart: false } },
  presets: { 'Новичок': { speed: 5 }, 'Безумие': { speed: 18 } },
  start(lab, scene) { /* построить мир новой партии */ },
  update(lab, dt) { /* один кадр игры */ },
  overNote(lab) { return ['Точность: 48%']; },  // заметки на экран конца партии
};
```

| Поле | Обязательно | Что делает |
| --- | --- | --- |
| `title` | да | Название на стартовом экране и ключ рекорда (если нет `id`) |
| `start(lab, scene)` | да | Строит мир новой партии. Вызывается при каждом старте и перезапуске на новой чистой сцене. Всё состояние партии кладётся в `lab.state` |
| `update(lab, dt)` | да | Один кадр игры. `dt` — секунды с прошлого кадра, не больше 0,05. Не вызывается в меню, на паузе и после конца партии |
| `controls` | да | Список `{ input, text }`, где `input`: `move` (← →), `move4` (← → ↑ ↓), `a` (главная кнопка), `b` (вторая). Подписи на экране и кнопки тача строятся по нему |
| `config` | да | Ручки геймдизайнера: `value, min, max, step, label`, по желанию `hint` и `restart: true` (перестроить партию). Значения в `lab.cfg.имя`. Ручка `lives` задаёт стартовые жизни |
| `presets` | да | Наборы значений ручек. «Как задумано» оболочка добавляет сама; «Новичок» обязателен |
| `decisions` | да | Три решения ученика: чувство, честность, выбор. Видны на стартовом экране |
| `camera` | нет | `top`, `iso` (по умолчанию), `diorama`, `side`, `behind` или объект `{ type, alpha, beta, target, distance, fov }` |
| `field` | нет | `{ w, h }` в метрах, центр в начале координат. По нему камера подбирает расстояние |
| `players` | нет | `2` — игроки делят клавиатуру (WASD + F/G и стрелки + K/L) или берут по геймпаду |
| `duo` | нет | Имя ручки: пока она ≥ 1, игра на одного (`players: 1`) работает как игра на двоих — раскладка вдвоём, второй геймпад, подписи. Ручку ставят с `restart: true` и пресетом «Вдвоём»: так в «Каменном стакане» включается дуэль двух стаканов. `lab.players` в `start` уже равно 2 |
| `physics`, `gravity` | нет | Включает физику Havok (`PhysicsAggregate`) |
| `sky`, `fog`, `accent` | нет | Цвет неба и тумана, плотность тумана, цвет всплывающих очков |
| `donor`, `subtitle`, `id`, `lives`, `notes` | нет | Подпись донора, подзаголовок, ключ рекорда, жизни без ручки `lives`, решения программиста |
| `overNote(lab)` | нет | Строка или массив строк для экрана конца партии: что показала телеметрия |

Код игры — классический скрипт, а не модуль: `const GAME = {...}` объявляется на верхнем уровне. Методы вызываются как `GAME.start(...)`, поэтому внутри них `this` — сам объект GAME, и вспомогательные функции можно класть в него же (`this.buildWave(lab, scene)`).

## Система координат

- Ось Y — вверх. Земля — плоскость XZ на высоте 0. Единица — метр: человек ≈ 1,8, дом ≈ 3.
- Камеры `top`, `iso` и `diorama` смотрят из −Z в сторону +Z. +X — вправо по экрану, +Z — «вверх по экрану», вдаль. Поле `field` лежит в центре: X от −w/2 до w/2, Z от −h/2 до h/2.
- Камера `side` смотрит вдоль +Z на плоскость XY: X — вправо, Y — вверх, поле от Y = 0 до Y = h. Глубина Z — для фона.
- Камера `behind` — камера за героем. Вызовите `lab.follow(герой, { distance: 9, height: 4 })`: камера встанет за спиной по `rotation.y` героя, вперёд — +Z героя.
- `lab.p1.y` положительный, когда игрок жмёт вверх. В видах сверху это обычно +Z.

## Объект lab

| Группа | Что есть |
| --- | --- |
| Babylon | `lab.BABYLON` (то же, что глобальный `BABYLON`), `lab.engine`, `lab.scene`, `lab.camera`, `lab.light.hemi`, `lab.light.sun`, `lab.shadows` (может быть `null` при качестве «быстро») |
| Партия | `lab.t` (секунды партии), `lab.dt`, `lab.state` (ваше состояние, обнуляется при перезапуске), `lab.cfg` (ручки), `lab.seed`, `lab.round`, `lab.playing` |
| Ввод | `lab.p1`, `lab.p2`: зажатые `left right up down a b`; `pressed.a` — нажата в этом кадре; `released.a` — отпущена; `x`, `y` — оси от −1 до 1 (стик или стрелки). В играх с `move` стрелка вверх тоже работает как A |
| Очки и жизни | `lab.score`, `lab.lives`, `lab.best`, `lab.addScore(n, где, цвет)`, `lab.hurt(где, текстПроигрыша)` → `true`, если удар прошёл (даёт неуязвимость 1,2 с, тряску, вспышку, звук, вибрацию и при 0 жизней конец партии), `lab.invuln`, `lab.blink()` → мигать ли героем сейчас, `lab.gameOver(текст)`, `lab.win(текст)` |
| Сочность | `lab.shake(0..1)`, `lab.flash(цвет, 0..1)`, `lab.hitstop(сек)`, `lab.burst(где, { count, color или colors, speed, size, life, gravity, up, dir })` (`dir: [x, y, z]` — искры летят в эту сторону, например сквозь врага по направлению удара), `lab.popup(где, текст, цвет, размер)`, `lab.pulse(меш, k, сек)`, `lab.whiten(меш или узел, сек = 0.08, цвет = '#ffffff')` — вспышка попадания: меш на миг заливается цветом (у копий `createInstance` не работает: вспыхнули бы все копии), `lab.warn(где, радиус, сек, цвет)` → `{ left, dispose() }` — круг-предупреждение на земле, `lab.vibrate(мс, сила)` |
| Звук | `lab.sfx.jump/shoot/coin/hit/explode/power/beep/warn/whoosh/win/lose()`, `lab.tone(частота, сек, 'square'/'sine'/'triangle'/'sawtooth', громкость, скольжениеДо, задержка)`, `lab.noise(сек, громкость, частотаФильтра, задержка)` |
| Случайность | Только через зерно партии: `lab.rand(a, b)`, `lab.randInt(a, b)`, `lab.pick(массив)`, `lab.chance(p)`. `Math.random` в игре не используется — иначе ссылка с `?seed=` не повторит мир |
| Математика | `lab.clamp`, `lab.lerp`, `lab.v3(x, y, z)`, `lab.dist(a, b)`, `lab.flat(a, b)` (расстояние по земле), `lab.near(a, b, r)`. «Где» — меш, `Vector3`, `{x, y, z}` или `[x, y, z]` |
| Мир | `lab.mat(цвет, { glow, alpha, unlit, shiny })` — материал из кэша; `lab.color(hex)`; `lab.ground({ w, h, color, y })`; `lab.shadow(меш)`, `lab.noShadow(меш)`; `lab.follow(меш, опции)`; `lab.setCamera(вид, опции)` |
| Интерфейс | `lab.hud('ключ', 'текст')` — строка под очками (`null` убирает), `lab.count('имя', n)` — счётчик телеметрии (имя с `_` — скрытый: уходит порталу, на экран конца партии не попадает; так считается секрет общей игры урока `_secret`; секунды срабатываний скрытого счётчика уходят в телеметрию `marks`, не чаще 4 раз в секунду), `lab.stat('имя', значение)` — показатель телеметрии |

Тени и свечение оболочка подключает сама. Каждый новый меш принимает тени и отбрасывает их, кроме помеченных `lab.noShadow` (копии `createInstance` наследуют пометку исходника). Свечение даёт `emissiveColor`: `lab.mat(цвет, { glow: 1 })`.

## Что делает оболочка (в игре этого не пишут)

- Экран старта с названием, донором, кнопками (клавиатура или геймпад — по последнему устройству) и тремя решениями. Пауза (P, Esc, Start, уход со вкладки). Экран конца партии: очки, время, личный рекорд, рекорд класса от портала, заметки `overNote`, телеметрия, зерно партии.
- Перезапуск: R, пробел или A после конца партии. Партия строится заново на чистой сцене.
- Нажатие, которым запущена партия, не засчитывается. Короткое нажатие между кадрами не теряется.
- Панель «Ручки геймдизайнера» (Tab или Select): ручки игры, пресеты, «Как задумано», ручки оболочки (тряска, сочность, свечение, качество графики), «Скопировать настройки».
- Звук M. Ошибка в коде игры останавливает игру и показывает сообщение со строкой, портал получает её для исправления.

## Связь с порталом

Игра работает в `iframe` и общается с порталом через `postMessage`.

| Направление | Сообщения |
| --- | --- |
| Игра → портал (`source: 'lab-game'`) | `ready` (версии и описание игры), `start`, `again` (сколько раз нажали «ещё раз»), `over` (очки, рекорд, зерно, телеметрия, изменённые ручки), `cfg`, `error` (фаза, текст, строка) |
| Портал → игра (`target: 'lab-game'`) | `records` (`{ record: { score, nick } }` — рекорд класса), `seed` (зерно-вызов), `setCfg` (значения ручек), `pause` |

Для автопроверки и отладки на странице есть `window.__lab`: `ready`, `state`, `lab`, `tele`, `session`, `cfg`, `DEFAULTS`, `confirm()`, `restart()`, `end()`, `togglePanel()`.

## Образец

`portal/games/nlo-v-stanice.js` — ремейк-донор урока 1 по мотивам механики Space Invaders и образец для Qwen. На нём видно, как выглядит игра по контракту:

- копии `createInstance` для повторяющихся предметов: 266 мешей, 134 вызова отрисовки;
- честное предупреждение: луч под НЛО и путь снаряда на земле, у золотого НЛО — путь каждого снаряда веера, пока оно заряжается;
- выстрел по правилам стреляющего героя (`ai/game-prompt.md`): заряд на стволе, ядро с огненным хвостом, отдача, искры сквозь врага (`dir`), вспышка врага (`lab.whiten`), «вжух» и «бум», сбитое НЛО горит, падает и оставляет пятно, очки крупнеют с серией;
- секрет донора — отдельной ручкой и пресетом «Без секрета»;
- телеметрия под понятие урока.

`portal/games/kamni-mudreca.js` — ремейк-донор урока 2 по мотивам крестиков-ноликов, второй образец для Qwen: пошаговая игра на сетке. Курсор по клеткам с повтором при зажатой стрелке, ход бота перебором (минимакс с отсечением, полное решение классики с запоминанием позиций, глубина и бюджет перебора — ручками), матч из нескольких партий с жизнями, режим «вдвоём за одним экраном» ручкой `vs`. Честность: камень, который исчезнет, заранее горит красным кругом, ветер показан стрелкой и призраком камня. Телеметрия — на каком ходу стал известен исход партии. 257 мешей, 111 вызовов отрисовки.

`portal/games/kamennyi-stakan.js` — ремейк-донор урока 4 по мотивам механики «Тетриса», второй образец для ИИ в уроке 4 (поле `sample` сценария): игра на сетке в реальном времени. Падение по таймеру с ускорением по уровням, сдвиг с автоповтором (задержка и шаг — ручками), поворот с отскоком от стенок, фиксация с задержкой, сбор линий со вспышкой и плавным оседанием, «мешок» и предпросмотр, тень приземления. Дуэль двух стаканов — ручка `vs` и поле `duo`: общая очередь камней, мусор сопернику, красный столбик входящего мусора. Мир — плато Лаго-Наки с дольменами, пихтами и Фиштом, небо темнеет с уровнем, сурок-болельщик. Части одного цвета склеены до общего меша (`merge`): 207 мешей, 147 вызовов отрисовки.
