# Портал «Лаборатория игр»

Онлайн-портал курса. Сейчас готово ядро игр (этап 1). Каркас портала — Фабрика, продюсер, сборка через Qwen, плейтест, аркада класса и панель учителя — появится на этапе 3.

```
portal/
  engine/   движок игр: Babylon.js 9.31.0 + физика Havok в vendor/, оболочка «Лаб3D» (lab.js), страница игры (game.html)
  games/    ремейки-доноры учителя: образцы механик для уроков и для Qwen
  ai/       промпты для Qwen: системный промпт программиста игр и шаблоны сообщений ученика
  tools/    сервер для разработки, автопроверка игр в браузере, сборка промпта
```

## Быстрый старт

Нужен Node.js 18 или новее. Зависимостей нет.

```bash
node portal/tools/serve.js          # открыть http://localhost:8080/
```

Откроется ремейк-донор урока 1 «Тарелки над аулом». Управление: ← → или A D, выстрел — пробел. Tab — «Ручки геймдизайнера», R — заново, P — пауза, M — звук. Геймпад работает сразу.

## Инструменты

| Команда | Что делает |
| --- | --- |
| `node portal/tools/serve.js [порт]` | Отдаёт `portal/` по HTTP. Игра: `/engine/game.html?game=../games/имя.js`, `&seed=число` — тот же мир для друга |
| `node portal/tools/check-game.js [игра] [--self] [--quick]` | Автопроверка игры в Chromium без окна. Снимки и отчёт — в `portal/.check/`. Нужен Playwright |
| `node portal/tools/build-prompt.js [файл]` | Собирает системный промпт для Qwen с образцом и версией Babylon |
| `node portal/tools/build-prompt.js --template new\|change\|fix` | Шаблон сообщения ученика |

## Как устроена игра

Каждая игра курса — один объект `GAME` на обычном Babylon.js. Его пишет Qwen целиком по замыслу ученика. Оболочка `lab.js` делает служебное: экраны, ввод, ручки, камеры, свет и тени, сочность, звук, рекорды, телеметрию. Контракт `GAME` и API `lab` описаны в [engine/README.md](engine/README.md), промпт для Qwen — в [ai/game-prompt.md](ai/game-prompt.md).

## Безопасность

- Ключ API Qwen и пароль учителя хранятся только на сервере в `config.json`, в репозиторий не попадают.
- Данные учеников и записи прохождений тоже в репозиторий не попадают (`data/` в `.gitignore`).
- Игры учеников будут работать в изолированном `iframe` на отдельном домене. Код игры не получает доступ к странице портала, общается с ним только через `postMessage`.
