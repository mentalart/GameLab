# Архив версии 1

Здесь лежит всё, что было сделано до перехода на версию 2.0 (17.10.2026): платформа на 2D-движке, прототипы занятий, программа версии 1 и паспорта пройденных уроков. Курс собирается заново с урока 1 на Babylon.js, а архив служит справочником: из него переносятся проверенные решения.

| Папка | Что внутри | Что взять в версию 2.0 |
| --- | --- | --- |
| `laboratoriya-igr/` | Платформа версии 1: сервер Node.js без зависимостей, очередь запросов к ИИ, сценарий урока 1, 2D-движок, промпты, интерфейс ученика и учителя | Сервер, очередь к ИИ, промпты продюсера и отзыва, типы шагов, панель учителя |
| `prototipy/zanyatie-2/` | «Крестики-нолики: одно правило», «Змейка-перевёртыш», квиз «Разбери игру на детали», «Мастерская одного правила», продюсер, плейтест, аркада | Ремейки урока 2, квиз-мини-игра, тап-карточка плейтеста, аркада |
| `prototipy/zanyatie-3/` | Фабрика MDA, 3D-игры «Башня из облаков» и «Хычин-рывок» на three.js, ядро `src/lab3d/` | Ядро Лаб3D (ввод, ручки, телеметрия, камеры) — переписать на Babylon.js; Фабрика и предсказание динамики — для урока 3 |
| `prototipy/zanyatie-5/` | «Два прыжка» и «Лаборатория прыжка» с 11 ручками | Вход и ручки урока 5 — перенести на Babylon.js |
| `docs/` | Программа версии 1 (PDF), журнал версии 1, паспорта уроков 1–2 | Открытия прохождения уже учтены в программе 2.0 и журнале |

Ключ API и данные класса из `laboratoriya-igr/` в репозиторий не попадают (см. `.gitignore`). Пути в скриптах `build.py` указывают на рабочую папку, где их запускали, поэтому перед сборкой их нужно поправить.
