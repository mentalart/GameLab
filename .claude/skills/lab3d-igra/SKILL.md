# Игра на «Лаб3D»

Ремейк-донор учителя — один объект `GAME` на three.js закреплённой версии поверх оболочки `portal/engine/lab-three.js` (страница `portal/engine/game.html`). Оболочка уже даёт экраны партии, ввод (клавиатура, два геймпада, тач), ручки и пресеты, камеру, свет, мягкие тени, свечение, сочность, звук без файлов, зерно, телеметрию, рекорды, призрака, бота-плейтестера и связь с порталом. Игра пишет только механику и мир.

Игры учеников сюда не относятся: их пишет Qwen в чате chat.qwen.ai страницей HTML с мостом `portal/engine/portal.js` (задание — `portal/ai/chat-prompt.md`).

## Источники правды

- Контракт, координаты, камера, объект `lab`, графика оболочки, бот-плейтестер — `portal/engine/README.md`. Читай его целиком перед первой игрой.
- Правила хорошей игры курса (план комментарием, нет доминирующей стратегии, кривая партии, три слоя яркости, понятность, шесть шагов ощущения действия, четыре партии в уме) — `pravila.md` рядом с этим файлом.
- Планка картинки и ощущения — `planka.md` рядом с этим файлом (см. ниже).
- Катсцены и синематики — правило `katsceny.md` рядом с этим файлом (решение автора 21.10.2026), механизм — `lab.cutscene` (README оболочки, раздел «Катсцены»).
- Образец по устройству — `portal/games/zvezdopad.js`; доноры уроков 1–8 — в `portal/games/`, лучший по виду — `nlo-v-stanice.js`.
- API three.js — только версии из `portal/engine/vendor/three/VERSION.txt` (0.170.0). Обновляет её только `bash portal/tools/vendor-three.sh`. Подсказки из сети могут быть для другой версии; дополнения — только те, что лежат в `vendor/three/addons/` (их же даёт `lab.addons`).

## Порядок

1. План комментарием в начале файла по `pravila.md`: фраза игры, ядро на 3 секунды, выбор риск — награда, 2–3 вида угроз, кривая партии, события сочности, лицо игры и палитра.
2. Код строго по плану; все важные числа — ручками, спрятанная механика донора — отдельной ручкой и пресетом «Без спрятанной механики», пресет «Новичок» обязателен.
3. Мир — лоуполи-деталями оболочки: `lab.box`, `lab.ball`, `lab.cyl`, `lab.cone`, `lab.ground`; повторяющееся — `lab.instances` + `lab.place`, неподвижное — `lab.merge`. Бюджет — 250 вызовов отрисовки.
4. Главного героя отметь `lab.hero(объект)`, камеру ставь через `camera` в GAME, `lab.follow` или `lab.setCamera`.
5. Сочность — вызовами оболочки (`lab.shake`, `lab.hitstop`, `lab.burst`, `lab.ring`, `lab.trail`, `lab.whiten`, `lab.popup`, `lab.pulse`, `lab.pitch`, `lab.slowmo`, `lab.tween`), не своими эффектами: тогда работают 12 переключателей сочности урока 6.
6. Случайность — только `lab.rand`, `lab.pick`, `lab.chance`: иначе `?seed=` не повторит мир. `THREE` на верхнем уровне файла не трогать.
7. Проверка: `node portal/tools/check-game.js games/<имя>.js` и `node portal/tools/playtest.js games/<имя>.js`, снимки в `portal/.check/`. Дальше — skill `proverka-i-kommit`.

## Планка картинки и ощущения

`planka.md` рядом с этим файлом: лицо игры и три фирменных приёма до кода, приёмы картинки three.js и чем они делаются в «Лаб3D», считаемый чек-лист сочности на главном действии, проверки дизайна, которых не видно на одном кадре, и сравнение снимков с эталоном жанра. Пройди его перед сдачей донора.

## Справочники в соседних skills

Код в них — на Godot и Unity. Бери правила и числа, а пиши вызовами `lab`:

- `game-feel` — уровни силы события: тряска 0,15 / 0,4 / 0,8 → `lab.shake`, стоп-кадр 0,05–0,12 с → `lab.hitstop`, вспышка 1–3 кадра → `lab.whiten`; сочность возвращается к покою и не мешает вводу.
- `camera-systems` — сглаживание без зависимости от частоты кадров (`lab.damp`), мёртвая зона, упреждение по движению, камеру не тянет тряска.
- `level-design` — сначала научить, потом проверить; напряжение пилой с передышкой перед пиком.
- `game-jam` — урезать замысел под время урока: сначала петля «старт → игра → проигрыш → снова».
