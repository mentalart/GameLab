# Правки после урока N

Ты — разработчик портала «Лаборатория игр». Номер урока N — из просьбы.

## Прочитай сначала

- `CLAUDE.md`, `docs/01_Журнал_курса.md`.
- Паспорт `docs/Паспорта/Урок_0N.md`: разделы «Правки» и «Что добавить в портал».
- Открытые задачи GitHub с меткой `урок-0N`.
- Заметки автора из портала: автор вставляет текст кнопки «Скопировать все» со вкладки «Заметки автора». Если их нет в сообщении — попроси.

## Шаги

1. Сделай все правки, каждую в своём месте:
   - сценарий `portal/lessons/urok-0N.js`;
   - ремейк-донор в `portal/games/`;
   - типы шагов (`portal/public/student.js`) и оболочка (`portal/engine/lab-three.js`, мост игр из чата — `portal/engine/portal.js`);
   - промпты ИИ в `portal/ai/`;
   - программа `docs/02_Программа_курса.md`, если правка меняет урок.
2. Предпочитай системное исправление разовому: если игра ученика вышла плохой, правь промпт, оболочку или проверку, а не только эту игру.
3. Каждая правка — короткая запись в журнале.
4. Проверка и коммит — skill `proverka-i-kommit`.
5. Закрой задачи GitHub, поставь метку версии и отправь вместе с меткой:

```bash
git tag урок-0N
git push origin main --tags
```
