# Лаборатория игр

Курс геймдизайна для старшеклассников (14–17 лет) в Школе креативных индустрий, пос. Тульский, Республика Адыгея, и локальная платформа, на которой проходят его занятия.

Курс учит не программированию, а мышлению геймдизайнера: придумать опыт игрока, превратить его в правила, проверить на живых людях и улучшить. Код игр пишет ИИ (Qwen), а решения принимает ученик. Каждое правило геймдизайна за 5–10 минут превращается в маленькую играбельную HTML-игру, и каждое занятие заканчивается тем, что другие играют в то, что ты сделал.

## Курс в цифрах

| Объём | 72 академических часа: 36 занятий по 2 часа, раз в неделю |

## Стандарты студии

Эти правила действуют в каждом уроке, прототипе и на платформе:

- **Ученик креативит сам.** Главная игра занятия не выдаётся готовой: каждый ученик придумывает и собирает свою, а теория урока разбирается на материале собственных игр. Готовые игры учителя служат только короткой разминкой.
- **ИИ исполняет, ученик решает.** Сначала три решения (чувство, честность, выбор), потом промпт по формуле «ИГРА»: И — идея и чувство, Г — глагол и кнопки, Р — правила, А — атмосфера.
- **Кубик предлагает, автор решает.** У каждого поля для идеи, решения или промпта есть кнопка-кубик со случайным вариантом; нетронутые варианты помечаются `[кубик]`, чтобы учитель видел, где ученик думал сам.
- **Всё интерактивно.** Вопросы, квизы и задания сделаны как мини-игры: кнопки, карточки, перетаскивание, таймер, очки, звук и мгновенный отзыв, а не текст со строкой ответа.
- **Геймпад с первой версии.** Каждый прототип управляется с геймпада, а меню и подсказки показывают его кнопки, если он подключён.
- **Ручки геймдизайнера (Tab).** В каждой игре есть панель со всеми важными числами и пресетами («Новичок», «Как задумано»).
- **Видно = правда.** Зона урона совпадает с тем, что видит игрок.
- **Плейтест после каждой игры** и отзыв учителя с одним понятием геймдизайна.

### laboratoriya-igr/ — платформа

Локальный сайт, который учитель запускает на своём компьютере; ученики открывают его в браузере в той же сети. Все идут по сценарию урока синхронно (чекпоинты открывает учитель), а замыслы, игры и Аркада у каждого свои.

- `server.js` — сервер, очередь запросов к ИИ, данные класса в `data/db.json`.
- `lessons/lesson1.js` — сценарий урока: тексты, плейтест, квизы, колоды кубиков.
- `engine/template.html` — движок игр: ИИ пишет только объект `GAME`, а старт, пауза, счёт, ручки, геймпад, тач-кнопки, звук и телеметрия уже встроены.
- `prompts.js` — инструкции для ИИ: программист, продюсер, отзыв учителя.
- `public/` — интерфейс ученика и панель учителя.
- `games/sova-haker.html` — общая игра урока 1 «Сова-хакер».

Запуск: Node.js 18+, затем `node server.js` в папке (или `Запустить (Windows).bat` / `Запустить (Mac).command`). Без ключа API платформа работает в демо-режиме, удобном для репетиции. Подробная инструкция для учителя — в [laboratoriya-igr/README.md](laboratoriya-igr/README.md).

Ключ API и пароль учителя хранятся в `config.json`, который создаётся при первом запуске и в репозиторий не попадает (см. `.gitignore`); образец — `config.example.json`.

### prototipy/ — прототипы уроков

Однофайловые HTML-прототипы, которые открываются прямо в браузере.

- **Занятие 2:** «Самолётик в телевизоре 2», «Крестики-нолики: одно правило», «Змейка-перевёртыш 2», квиз «Разбери игру на детали», «Мастерская одного правила», «Продюсер читает замысел», плейтест и «Моя Аркада».
- **Занятие 3:** «Тетрадь занятия 3» (MDA), «Фабрика MDA» и 3D-игры учеников «Башня из облаков» и «Хычин-рывок», «Змейка-перевёртыш 3».

В `src/` лежат исходники игр в формате `GAME` для движка платформы и скрипты сборки (`build.py`); пути в скриптах указывают на рабочую папку, где их запускали, поэтому перед сборкой их нужно поправить.

Курс развивается урок за уроком: сначала урок проходится вживую (учитель и ученик), по итогам пишется паспорт урока, затем по паспорту в платформу добавляются сценарий `lessonN.js`, новые типы шагов и общая игра урока.
