# Лаборатория игр

Курс геймдизайна для старшеклассников (14–17 лет) в Школе креативных индустрий, пос. Тульский, Республика Адыгея, и онлайн-портал, на котором проходят его занятия.

Курс учит не программированию, а мышлению геймдизайнера: придумать опыт игрока, превратить его в правила, проверить на живых людях и улучшить. На каждом занятии ученик берёт яркую механику известной игры, разбирает её секрет и делает на её основе свою 3D-игру по формуле Донор × Твист × Мир. Код пишет Qwen по API, решения принимает ученик. Каждое занятие заканчивается тем, что класс играет в игры друг друга и бьёт рекорды авторов.

## Курс в цифрах

| | |
| --- | --- |
| Объём | 72 академических часа: 36 занятий по 2 часа, раз в неделю |
| Группа | 10–14 человек, у каждого свой компьютер; опыт программирования не нужен |
| Практика | 54 часа из 72 (75% времени ученики делают игры и играют) |
| Результат ученика | 25+ игр в аркаде класса, из них 7–8 релизных версий 1.0; своя законченная игра и показ на Фестивале игр |
| Формула занятия | донор → секрет → своя игра → играем вместе → открытие |
| Движок игр | Babylon.js с физикой Havok и CC0-моделями |

## Как идёт разработка

Курс собирается заново с урока 1 по программе версии 2.0. Сначала ядро на Babylon.js и проверка, что Qwen пишет играбельные 3D-игры, потом каркас портала, потом урок за уроком:

1. «Сборка» до урока: сценарий, ремейк-донор, квиз, колоды кубиков.
2. «Прохождение»: урок идёт через портал, игры пишет настоящий Qwen.
3. Разбор: паспорт урока, запись в журнал, правки задачами GitHub.
4. «Сборка» после урока: правки, автопроверка, коммит в main.

Правки идут сразу в основную ветку: Claude коммитит и отправляет их сам (в Claude Code — хуком автокоммита), сливать вручную ничего не нужно.

Портал разрабатывается и запускается из репозитория (локально или в облачной среде) и переезжает на хостинг в России, когда курс готов; пробный выезд — после модуля 1.

Ключи API, `config.json` и данные учеников в репозиторий не попадают (см. `.gitignore`).
